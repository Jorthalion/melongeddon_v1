# Melongeddon

A single-player tower defense: defend the Midnight Library from melons, corn, and pumpkins.

Standalone Vite + React + Tailwind project, extracted from the original Grok app-builder export.

**New here? Read the [Setup and Player Guide](docs/GUIDE.md)**: how to install and run it, publish your own copy, and how to play (controls, keepers, towers, upgrades, enemies, nights and tips).

Play online (once GitHub Pages is on): https://jorthalion.github.io/melongeddon_v1/

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build into dist/
npm test         # engine tests
npm run sim      # balance simulator -> sim-results/report.md (add -- --seeds 10 for more runs)
npm run sim -- --strategies human   # the same, played by the human-like test bot (see Tuning)
npm run sim:scenario -- scripts/scenarios/lamp-three-melons.json   # one question, A against B (see Tuning)
npm run sim:abuse   # which tower, spammed with everything aimed at it, wins the most? (see Tuning)
npm run sim:abuse -- --pairs   # which pair of towers, spammed together, wins the most? (see Tuning)
npm run sim:newplayer   # a first-time player in a real browser: where do newcomers get stuck? (see New-player bot)
npm run animate  # tower and enemy animations via Blender (add -- towers, -- enemies, -- pops, -- builds, or -- trebuchet melon)
```

## Publishing

The build uses relative paths, so `dist/` runs from any folder or domain.

- **Windows installer:** `npm run installer` writes `release/installer/Melongeddon-Setup-<version>.exe` (Electron; code in `electron/`, settings under `"build"` in `package.json`). Pushing a tag like `v0.2.0` runs `.github/workflows/release.yml`, which builds, smoke-tests (`MELONGEDDON_SMOKE=1`) and publishes it as a GitHub Release. See the guide for the long-path workaround.
- **Installable web app:** the hosted build is a PWA (`public/manifest.webmanifest`, `public/sw.js`). The build writes `dist/precache.json` (every file) so the service worker can cache the whole game for offline play; the Title shows **Install app** when the browser offers it. Fonts are bundled (`@fontsource-variable`), so offline copies look the same.

- **itch.io:** `npm run package` writes `release/melongeddon-web.zip`. Full step-by-step page setup, description, tags, cover and screenshots: [docs/itch/ITCH.md](docs/itch/ITCH.md).
- **Netlify:** connect the repo (settings come from `netlify.toml`), or drag the `dist/` folder onto app.netlify.com/drop.
- **GitHub Pages:** push to GitHub, then in the repo's Settings → Pages set Source to "GitHub Actions". `.github/workflows/pages.yml` tests, builds and deploys on every push to `main`/`master`.

Optional: once you know the final URL, make `og:image` in `index.html` an absolute URL so link previews show the poster.

## Nights

Midnight is 21 waves (`MIDNIGHT_WAVES`; `nightLength(night)` gives each night's length). Act one is waves 1–6; act two is the next nine and ends on Unchaperoned; act three is six more waves, climbing slowly from wave-15 health. A shelf opens after wave 15. Act three brings three new fruit, all flags on existing kinds (`pit`, `gall`, `borrower` on `SpawnSpec`), each with its own sprite (`public/sprites/enemy-pit.webp`, `enemy-gall.webp`, `enemy-borrower.webp`; a ring or dot stands in while they load). Galls draw last, so a rider is never hidden under the pumpkin behind its host. A **pit** is a stone melon: splash, fire and puddles do only `BALANCE.pitResist` (12%) of their damage to it, so a direct shot does the work; it is not a guard, so the Peeler can't strip it. A **gall** is a small corn rider that sits a step behind a pumpkin and heals it `BALANCE.gallHeal` (6%) of its health a second while both live; pop the rider and the pumpkin is only a pumpkin. A **borrower** is a fast, frail corn that costs no stack at the door but takes `BALANCE.borrowTake` (12) seeds. The finale, "The stacks, again", is Karl with borrowers ahead of him. The Overflow is still 15 waves (`WAVE_COUNT`) and doesn't use act three's fruit. Nobody comes to the door: the knight's visit, its alliance and its betrayal were removed. The Overflow ends with "The meter spends" and "Up the chute", when absurdity drops rinds down the chute. Enemy health climbs the full curve through wave 6, then `BALANCE.storyHpPace` (0.375) of a step per wave up to wave 15, so wave 15 is as tough as the old 10-wave finale. From wave 15, Midnight's act three keeps climbing at `BALANCE.actThreeHpPace` (0.3) of a step a wave (`storyHpStep`), and each of its waves puts a mix behind its one new fruit, so waves 16–20 climb into Karl instead of resting before him. The Overflow multiplies enemy health by `BALANCE.overflowHp` (1.4): at 1.0 the simulator won 96% of Overflow nights on Normal against 69% for Midnight; at 1.4 it is 72% on Normal and 35% on Melongeddon (Midnight: 38%).

**The Overflow's chute.** From wave 6, some fruit come up the returns chute: they appear past the far end of the carpet and walk it backwards, and one that reaches the entrance costs a stack. Waves 6–9, 11, 13 and 14 send shelled melons up it; waves 14 and 15 also drop a shelled melon per 25 absurdity, and wave 15 sends Karl. A **CHUTE** plate and arrows mark that end of the carpet: they glow blue and move while the current or next wave uses the chute (`hud.chuteWave`), and sit dim otherwise. The first chute wave also shows a one-time tip (`melongeddon:chute-tip`; Settings › Show tips again brings it back).

**The Siege (night three).** `NightId` `"siege"`, 15 waves (`SIEGE_WAVES` in `rules.ts`, through `waveAt`) on its own map, `BOARDS.courtyard` (22 × 14, a 46-tile `carpet: "path"` with two 45° stretches, hedges, six `statues` and a 2 × 2 `fountain` as shelf cells, and two `drops`). It opens after the Overflow: the Catalogue ledger counts story wins by night (`Ledger.winsByNight`, filled by `addNight`; `parseSave` backfills an Overflow win from an old `winsByMap.overflow` or the Overflow achievements), `hud.siegeOpen` reads it (developer mode opens it; `WorldOptions.siegeOpen` forces it for the simulator and previews, `WorldOptions.ledger` seeds it for tests), and `chooseNight("siege")` refuses with "Win the Overflow first." until then. The Overflow's victory card offers **Continue to the Siege** (`api.continueSiege`; `victoryAction` in `keys.ts` names the button and Enter does the same); the Siege's offers **Set up Endless**. It starts with the keeper's usual seeds plus `BALANCE.siegeSeeds` (60, shown on the checkout card's "Tonight" group with the Overflow's crates), climbs the story health curve with no multiplier of its own, and pays fragments like the Overflow (`FRAGMENTS.siegeBonus`). Its intro is its own poster ("Night three", "The Siege", `SIEGE_JOKE`). There is no fruit in it: two new kinds, **`goose`** and **`cat`** (`STATS`), and six flags on them (`SpawnSpec` `gosling`, `matriarch`, `boxed`, `para`, `tank`, `general`; `QueueItem.siege`). Every number is in `SIEGE` in `rules.ts`. A plain goose is a **Honker**: its first hit sets `Tower.honked` on every tower within `honkReach` (1.5 tiles), which skips its next shot. **Goslings** come in lines of `goslingLine` (5; `QueueItem.line`, the first is the `leader`); a dead leader halts its line `goslingStun` (2 s, `Enemy.halt`). **The Matriarch** (boss) sets `rallied` on every goose every `rallyEvery` (6 s) for `rallyTime` (3 s) at ×`rallySpeed` (1.5). A plain cat is **Private Whiskers** (`lives9`): the first lethal hit leaves it at `nineLives` (30%) unless it was one hit from full health worth `oneLife` (130%) of it. A **Box Cat** is skipped by every tower's aim except the area towers in `BOX_SEERS` (the Cauldron and the Quack-Liber count: they lob a puddle or a burst); splash, burn, pulp or a Reading Lamp's reach knocks the box off (`unbox`). A **Paratrooper** never walks in: its queue item becomes a pending landing (`world.landings`) that lands on `BOARDS.courtyard.drops[drop]` after `dropGlow` (3 s), under a parachute for `dropFall` (`descend`), and `hud.dropWave` lights the targets before the wave. A **Cardboard Tank** takes ×`tankArmour` (0.5) from a shot or splash whose source (the tower, or where a splash landed) is ahead of it along the carpet, and costs 2 stacks at the door (`leakOf`). **General Mittens** (boss) gives every cat ×`generalBonus` (1.25) health while she lives (`mittened`), and on her death every cat loses it and walks back `scatter` (2 s, through `driven`). Both bosses cost 3 stacks and pay +2 stacks like Karl. **The feud** (`tickFeud`): a non-boss goose and cat within `feudReach` (half a tile) both `halt` for `feudTime` (2 s) and lose `feudHit` (10%) of their max health (`hurt` via `"feud"`, which skips every modifier), once per pair, drawn as a dust cloud (`world.brawls`). The **Anti-Geese Protocol** throws geese ×`protocolThrow` (2) as far and sets `panic` (`protocolPanic`, 2 tiles), walked back in the Driver's branch. One-time tips (`SiegeTip`, keys `melongeddon:siege-tip:feud` and `:drop`) show the first fight (`hud.feuds`) and the first drop (`hud.dropSeen`). The Courtyard's flagstones, hedges, statues and fountain are painted (`tile-floor-courtyard`, `prop-hedge`, `prop-statue`, `prop-fountain`), with the code-drawn versions in `src/game/drawSiege.ts` as fallbacks while they load. The geese and cats are painted (`enemy-honker`, `-gosling`, `-matriarch`, `-whiskers`, `-boxcat`, `-para`, `-tank`, `-general`, registered in `draw.ts`), with Blender walk and pop strips (`npm run animate`); `drawSiege.ts` draws them only while the files load. Achievements: a "Courtyard" set on the Atlas Room shelf (`Achievement.set`), counted in `RunLog.feuds`, `protocolGeese`, `boxesOff` and `oneLife`. Tests: `tests/siege.test.ts`. Tuning (simulator, `--seeds 2`, Story / Normal / Melongeddon / Overdue): the Siege wins 73 / 47 / 16 / 6% against the Overflow's 88 / 53 / 23 / 13% (4 seeds: 76 / 50 / 17 / 7%), with geese at 36 health, cats 45, tanks 140, the Matriarch 340, the General 380 and 60 extra seeds; fewer Box Cats and paratroopers than first written, and one fight at a time per animal (otherwise a stopped cat fought every goose that walked up and whole waves jammed at the entrance). Nearly all of the Story gap is the melon-only bot (31%), which has no answer to a Box Cat; the other bot strategies win 87% on Story, as on the Overflow.

## Keepers

Seven keepers, picked on the setup screen (keys 1–7). Each has a perk and a **signature tower**: only that keeper can build it, one at a time, from the **Keeper** tab (key R). Mynxi's, Vaelithra's, the Legal Elf's, Ooze Clues' and Dr. Samodovol's tabs also hold more keeper towers (the Legal Elf and the Doctor have three): the Reserve Desk, the Unstoppered, the Foot of the Law, the Honeyed Heel, the Copycat, the Study and the Archaeological Dig (`KEEPER_TOWERS` in `rules.ts`; `SIGNATURE` is the first of each list). A keeper tower can have an unlock goal (`TOWER_GOALS` in `meta.ts`, tracked in `MetaStats`); until it's met the tower shows a lock on the build bar. Keeper perks that name the signature tower apply to it only. Keeper towers can't be fitted in the back room, except the Unstoppered, which takes a Still's fittings, the Lion Blade and Nexus Spire with their own, and the Scales of Justice with Billable Hours (`billable`).

## Difficulty

Four levels on the setup screen. They scale enemy health and speed (`DIFFICULTIES` in `src/game/rules.ts`):

| Level | Health | Speed | Simulated bot win rate |
|---|---|---|---|
| Story | 0.75× | 0.9× | ~97% |
| Normal | 1× | 1× | ~77% |
| Melongeddon | 1× → 4× | 1.12× | ~65% (human bot) |
| Overdue | 1.2× → 4.5× | 1.15× | ~33% (human bot) |

Melongeddon and Overdue health climbs over the night: `hp` on the first wave to `hpLate` on the last, shaped by `hpBend` (2: slow early, steep late), in `difficultyHp`. ## Endless mode

Pick **Endless** as the night on the setup screen (New night). You play act one's six waves, then generated waves that cycle four themes (corn swarms, shelled melons, pumpkins, a mix), grow every other wave, and add armoured variants from wave 13. Karl comes every fifth wave. You get an upgrade pick after waves 1, 2, 4 and 6, then every `ENDLESS_PICK_EVERY` (3) waves. Enemy health follows the story curve to wave 10, then grows `BALANCE.endlessGrowth` (15%) per wave. In simulation, Normal runs end around waves 17–19 and Easy around 25. Best endless score is saved separately.

**Shelves: small and often.** `nextBeat` opens a shelf after waves 1 and 2, then every `PICKS.every` (2) waves (Midnight also after wave 15): 7 shelves on a 15-wave night, 11 on Midnight. From the third shelf on, the offer leads with **tower picks** (`TowerPickId`, `"melon:dmg"`): one kind's damage ×(1 + `PICKS.dmg`), fire rate (interval ÷ 1 + `PICKS.rate`) or reach ×(1 + `PICKS.range`) per rank, up to `PICKS.maxRank` (3) ranks, stored as repeats in `hud.upgrades` (`rankOf`, `canTake`). `towerPicksFor` lists them for the built kinds in `PICK_KINDS` (shared towers only), most-built first, least-taken stat first; `pickStatsFor` drops a damage pick for a tower with no damage and a reach pick for a whole-board one. `towerReadout` applies them on top of `baseReadout`, so the inspector, the back room and every shot see them. The simulator's `smartPick` scores a tower pick by how many of that kind are out. Fines (3) and the Lamp (+26) stay a little stronger than the rest, because Mynxi, the Doctor, Quackarot and Asser lean on them: at 2 and +18 the human bot fell to 9–47% on Melongeddon with those keepers. Every upgrade card has a 40px mark (the tower's picture, or a drawn mark for shared upgrades) and a small tag in player words saying what it reaches ("Melon cannons", "Cannons and precision", "The ledger"). The keeper's own cards (Mynxi: Overdue Fines and Reading Lamp; Sir Michael: Heavy Caliber and Knight's Splatter; Vaelithra: Trial Vial and Distilled Batch) have a gold edge and the keeper's name; hover and keyboard focus show the same gold edge. **Floors.** A board may list `floors`: straight runs of carpet tiles (`from`/`to`, in the carpet's direction) that are a `belt`, `up` or `down` stairs, or a growth `bed`. `floorTiles(map)` expands them to `world.floors` ("c,r" to kind and direction); the movement step multiplies by `floorPace(kind, back)` (walking toward the entrance, a chute walker or a driven fruit, takes the inverse). Beds heal in the enemy loop unless the fruit burns. A board with a `bell` gets `world.bell` (`next`, `quiet`), counted down by `tickBell` during waves and reset at each wave start; while `quiet` is above 0 the tower loop skips every tower. The marks are drawn by `drawFloors` and `drawBell` in `draw.ts`; painted art is listed in `docs/art/MAP_PROMPTS.md`, and the design notes are in `docs/new-maps-design.md`.

**Targeting.** Each aiming tower has a `Tower.target` (`TargetMode`: first, last, strong, weak, close, armour, boss, fresh) chosen in the inspector or with `A` (`api.cycleTarget`); its kind's recommended mode and the modes it offers are in `DEFAULT_TARGET` (`rules.ts`), `fresh` ("first, not affected") uses `FRESH_TEST` in `engine.ts`, and a new tower starts on the mode last set on its kind that night.

**Screen layout.** `layoutFor` (`src/lib/layout.ts`) works out the board's drawn width in the normal layout (board over the build bar) and the wide one (build column left, back room right) and picks wide only if its board is at least as big, within `WIDE_SLACK_PX`; both lose `BAR_REM` to the Coming up bar. Tips (`TipCard`, `Tips` in `TutorialHint.tsx`) never sit on the board: MelonGame's tip dock puts them in a line under the Coming up bar (a `more` toggle; `TipFit`), in full in the wide layout's right column, and above the build bar under `NARROW_PX` (640). Under `NARROW_PX` the Back room is a button beside Start wave (`BackRoomTab compact`, passed to `BuildFooter` as `backRoom`); its panel still opens as a sheet over the board. Tests: `tests/layout.test.ts`, `tests/tips-layout.test.ts`.

**Coming up bar.** `api.wavePreview(index)` returns a wave as it will walk in: `queueFor(index)` builds the queue for both the preview and `startWave` (late-slip extras, room fruit via `assignNatives`), and `spawnNumbers` gives each enemy's real health and speed (Siege sizes, mini-bosses, borrowers). Groups of identical enemies, notes for mid-wave extras, a threat (health × speed, bosses ×3, tanks ×2) ranked 1–5 against the night, a trend and up to three flags. `api.comingUp()` is the next wave between waves and what's still queued (plus landings) during one. `counters.ts` holds one table of what beats what, read by `ComingUpBar`'s "Your towers don't answer…" line and the enemy card's "Beaten by". The simulator's bot turns the crank that puts the most carpet in reach of its towers (never one that would idle a carpet-side tower) and the report counts cranks and jams. Tests: `tests/compact.test.ts`.

**The Flooded Basement: water that rises during each wave.** `BOARDS.basement` (18 × 12, `hp` 0.6, in by the cellar stairs at the top right; the spawn walks in along the first straight for any board that doesn't start on the left edge) has `heights` (`low` and `mid` tile lists, built by `basementHeights`: low is the carpet and the tiles touching it in the middle of the room; every other tile is high; `heightTiles(map)` → `world.heights`). `world.water` (0–3, copied to `hud.water`) rises during a wave with the share of the wave's queue spawned (`waterFor`: level 1 at `BASEMENT.rise[0]`, 2 at `rise[1]`, and 3 at `deepRise` on `deepWave`s, as `deepOn` sets for the difficulty: none on Story, the night's last on Normal, every 10th and the last on Melongeddon and Overdue) and drains in `endWave` (`drainWater`). `floodedTile(world, c, r)` is the one test: low at level 1+, middle at 3, unless a Sump Pump stands within one tile. Hooks: `paceOf` × `wade(e)` (`wadeSlow`, `wadeSlowBoss`; the Water Melon's `snorkel`); the tower loop skips a `soaked` tower (and so does the Gate's portcullis), lamps and Quack-Liber auras don't count from water, Compost Heaps and Reserve Desks don't pay; `addFire` melts ice and fizzles on water, and `tickWater` puts out fire patches and burning fruit in water; a Freeze hit on a fruit in water calls `freezeWater` (`world.ice`: every fruit on it gets `stomped`, bosses for `iceHoldBoss`); `addPool` and the Cauldron's puddle are `puddleWide` wider; the Electric spark reaches `chainReach` farther between two fruit in water. Room fruit: **Water Melon** (`watermelon`, melon base) and **Drain Gourd** (`draingourd`, pumpkin base: one that leaks, or is alive at the end, sets `hud.plugged`, so the water stays at 1 through the break and the next wave starts there; `runLog.plugs`). The **Sump Pump** (`pump`, Support, `BASEMENT.pumpCost`) is a room tower: `ROOM_TOWERS` adds it to the Support tab on its map only (`tabKinds`), `chooseBuild` refuses it elsewhere, and the Copycat can't copy it. The Coming up bar marks level-3 waves (and a plugged drain). Drawn by code (`src/game/drawBasement.ts`) until each painted file exists: `tile-floor-basement-low/mid/high`, `water-overlay`, `prop-gauge`, `prop-pipe`, `sig-pump`, `fruit-watermelon` and `fruit-draingourd` (`.webp` in `public/sprites/`; prompts in `docs/art/PROMPTS.md` §2a6). Unlocked by a 17-fragment Catalogue room. The simulator's bots weigh a tile by the share of a wave it stays dry (low ×0.35, middle ×0.9), build a pump in the low middle once five towers stand and more wherever one keeps two or more towers dry at the coming wave's top level, and keep Freeze high; the report shows the share of tower-time spent waterlogged (`runLog.soakedTime / towerTime`). Tests: `tests/basement.test.ts`.

**Room fruit.** A board may set `natives: { common, elite }` (a `NativeId`; only the Sorting Room, the Greenhouse and the Bell Tower do). `buildQueue` expands the shared wave with `waveQueue` and `assignNatives` swaps fruit in place: from wave `NATIVES.commonFrom` (4) every `commonEvery` (4)th plain fruit of the common's base kind, and from `eliteFrom` (10) the first plain fruit of the elite's base kind (two from `actThreeFrom`, 16; none on Story). A plain fruit has no guard or flag and isn't Karl or a chute fruit. Each is a flag on the enemy (`native`): Express Corn ignores slows, stops, honey and the Driver on a belt and rides it at `expressBelt` (2); a Parcel is `wrapped` (direct hits ×`parcelWrapped`, any splash, burn or pulp unwraps it) and drops `parcelContents` (3) corn that pay nothing; a Sprout grows into a melon after `sproutGrow` (2) s on beds or vines unless burning; a Creeping Squash lays `world.vines` every `vineEvery` (1.5) s that heal like a bed for `vineLife` (6) s, burn away under fire and wither `vineWither` (1) s after it dies; each Chimer runs the clock `chimerRush` (25%) faster, up to `chimerMax` (2×); a Gargoyle Gourd moves ×`gargoyleAwake` (3) while the bell's `quiet` is on and takes ×`gargoyleSkin` (0.75) otherwise. The first of each per night sets the log line in `NATIVE_INFO` and `hud.nativesSeen`, which shows the room's one-time `NativesTip`. Sprites `enemy-express`, `-parcel`, `-sprout`, `-squash`, `-chimer`, `-gargoyle` and `tile-vine` are registered in `draw.ts` with drawn stand-ins until the art lands (prompts in `docs/art/ENEMY_PROMPTS.md`).

**Board size.** A board may set `cols`/`rows` (default 16 × 10); `boardSize(map)` gives cells and world pixels, and the world carries them as `world.cols/rows/w/h`. Drawing, input (`fitBoard`), previews and the simulator all read the world's size, so a bigger board simply draws at a smaller scale. `GLOBAL_RANGE` (1400 px) is larger than the biggest board's diagonal. Without their health bonus the long carpets made the big maps much easier (Midnight on Normal: Great Hall 89%, Reading Room 97%, Stacks 71%). With `hp` 1.2 and 1.4 they simulate at 69% / 46% (Great Hall) and 82% / 32% (Reading Room) on Normal / Melongeddon, against 71% / 42% for the Stacks.

Maps open with Grand Catalogue rooms (`ROOMS` in `src/game/catalogue.ts`; `MAP_GOALS` in `meta.ts` only holds the "Restore …" text). Map cards and the intro screen draw the real board (`src/components/MapPreview.tsx`). In simulation the five classic maps play within a few points of the Stacks. Rare Books is the easiest without its health bonus; the Archive is the hardest for the bot, which doesn't plan lamp placement.

## Late slips

The Overflow's setup screen offers up to three optional **late slips** (`src/game/slips.ts`): Heavy Returns (chute opens on wave 3), Damp Powder (−20% damage), No Refunds (selling pays 0), Short Shelf (−4 stacks) and Karl Is Early (extra Karl on wave 8). ## Mynxi's tutorial (guided first night)

A new player's first **Start** plays Mynxi's tutorial: Midnight on the Stacks as Mynxi, on Normal, made very easy. Fruit have 30% of their health and 80% of their speed, and the night starts with +80 seeds and +8 stacks (`tutorialHp`, `tutorialSpeed`, `tutorialSeeds`, `tutorialStacks` in `BALANCE`; applied through `tune()` and `tutorialStart()` while `hud.tutorial` is on, restarts included). In simulation, a player who builds only the two cannons the lessons ask for holds with no leaks to wave 8; one who adds a cannon every third or fourth wave wins; one who adds a cannon a wave wins without a leak. She talks the player through 13 lessons in a speech box (`src/components/MynxiTutor.tsx`):

1. **Talk** (Next): welcome, the carpet and stacks, seeds.
2. **Build** a Damage cannon, then the range ring (talk).
3. **Build** a Control or Support tower, then the five tabs, the keeper tower and trick cannons (talk).
4. **Start** the wave, then speed and pause (Next, or change the speed), and holding the carpet.
5. **Pick** an upgrade card after wave 1.
6. **Open** the back-room tab before wave 2 and buy an upgrade (that one is free).
7. A last word on selling (talk).

Talk steps have a Next button; the others wait for the player, and building early skips the lessons it covers. The wave won't start while a step before it is open (`GUIDE_HOLDS`); pressing Start wave says why. Leaving the back room saves `melongeddon-guide` = `done` and opens **New night**. For the rest of that night (`hud.tutorial`) she chips in once each for a leak, Karl, affording her Card Catalogue, and the win or loss. **Skip** (on the box, or **Skip the guide** on the Title) ends it, and **Tutorial** on the Title replays it (`api.startTutorial()`). The steps are `GuideStep` / `GUIDE_STEPS` / `GUIDE_TALK` in the engine; her lines are `LESSON` and `TIPS` in the component. Her four expressions (`FACE`) all use the portrait until the art in [docs/art/MYNXI_PROMPTS.md](docs/art/MYNXI_PROMPTS.md) arrives. Tests and the simulator never see the tutorial unless they pass `guide: true` to `createWorld`.

## Saves

Saves are separate `localStorage` keys; `melongeddon-save-version` says which layout they are in (`SAVE_VERSION` in `src/lib/saves.ts`, now 1). `migrateSaves()` runs before anything reads them: saves with no version (v0.5.0 and earlier) count as version 0 and are migrated (players with progress skip the guided night); an unreadable version clears progress but keeps preferences; a newer version is left alone; a save that isn't valid JSON is dropped. To change a save layout, bump `SAVE_VERSION` and add a step to `MIGRATIONS`.

## Developer mode

Settings › **Developer mode** (`melongeddon-dev` in localStorage) reloads the game with `ALL_UNLOCKED` stats and `maxedProgress(0)` keepers, a DEV badge, and `api.devSeeds()` (+`DEV_SEEDS`, 500) in the pause menu. While it is on, lifetime stats, best waves and keeper XP are not written (`persistStats`, `persistKeepers`), so switching it off restores the real progress. Tests can pass `dev: true` to `createWorld`.

## Keeper levels

Each keeper levels from 1 to 10 by clearing waves as that keeper (10 XP a wave, +50 for a win, scaled by difficulty: Story ×0.5 up to Overdue ×2). Levels 2, 4, 6, 8 and 10 each open a choice of two perks, picked on the setup screen and swappable before any night. Level 10 offers a second copy of the keeper's signature tower or a keeper-specific capstone. Data, XP curve and storage live in `src/game/levels.ts`; the engine applies the merged effects (`perkFx`) when a run starts. The full perk list is in [docs/GUIDE.md](docs/GUIDE.md#keeper-levels-and-perks).

Simulated win rates (all strategies, maps and doors, one seed): level 1 is 69% on Normal and 38% on Melongeddon; a level 10 keeper is about 80% and 50%. Ooze gets slightly bigger perks and Sir Michael smaller ones. Dr. Samodovol's perks bend the Doctor's pick and the Lectern (Footnote, Annotated, Cited Edition, Midpoint, Carried Note, Second Opinion, Lecture Notes, Close Reading, and Second Lectern alone at level 10). Quackarot's perks bend his turret: its reach and speed-up (Wide Wake, Steady Hands), its burst (Heavy Payload), a speed-up after its kills (Quiet Confidence), a slowing patch every fourth rocket (Lane Lockdown), sticky targets (Covering Fire), and at level 10 a second turret with a slowing line between the two (Defensive Perimeter). The Legal Elf's lean on his feet and his court: Sustained (`fx.objections`, two Objections a wave), Heavy Footed (`stompWide`, 30% wider), Prompt Drop (`promptDrop`: after every `ELF_VALUES.promptEvery` (5) cleared waves an extra shelf from `promptOffer`, two ordinary cards and one of the `UNHINGED` cards: Unhinged Cyberpop, Billable in Advance, Malpractice Insurance, Pro Bono, each a boost and a drawback, marked "unhinged" in `CardPicker`), Sticky Situation (`sticky`: 4 prints, 10 s), Precedent (+0.06 to both Scales shares), Contempt of Court (`stompHoney`), Class Action and Second Foot (`stompExtra`, checked in `signatureBlocked` like `sigExtra`). Picks are stored by row and side, so saves from before a perk swap load as the new perk in the same place. The simulator takes keeper levels through `keepers` in `RunConfig`.

## The Grand Catalogue (fragments, rooms, achievements)

**Rooms and fragments** (`src/game/catalogue.ts`). Fragments come from finished nights (`FRAGMENTS`, `nightFragments`: a story win pays 1/2/3/4 by difficulty, +1 for the Overflow, +1 for popping Karl, 1 for a story loss after wave 10, 1 per 10 Endless waves) and from achievements (their `tier`, paid once, via `settle` in `achievements.ts`). They're spent on `ROOMS` (`restoreRoom` on the Title or Setup); each room's `rewards` open maps, keepers, bookmarks, keeper towers and cosmetics at once. `unlockedMaps`, `unlockedIds` and `lockedTowers` in `meta.ts` now take the restored rooms; `hud.lockedKeepers` gates `pickKeeper`/`chooseHero`, and `validateSetup` falls back to Mynxi with a note. A new player has only The Stacks (Mynxi, Vaelithra, Sir Michael, the Stacks and the Annex). Tests, the simulator and dev mode see every room (`options.rooms` picks some for tests). Cosmetics (`Cosmetics`: carpet dye, keeper-card frame, gilded title) are code-drawn, chosen in Settings › Appearance, and never touch play. **Migration:** on the first load after the change, `migrate()` restores for free every room with a reward the player already had under the old goals (kept as `LEGACY` in `catalogue.ts`: maps, bookmarks, keeper towers) or a keeper with XP, pays for achievements already earned, and leaves a one-time note on the Title. The save is the achievements key, `melongeddon-achievements`, now also holding `fragments`, `fragmentsEarned`, `rooms`, `migrated` and `cosmetics`.

**Balance (estimate).** Simulated Normal nights on the Stacks at level 1 (mixed strategies) pay about 2.0 (Vaelithra, 67% wins) to 2.8 (Mynxi, 92%) fragments a night before achievements; early achievements add roughly 3 on the first night and about 20 over thirty. Buying rooms cheapest first, the first room comes after night 1, The Archive around night 5, The Great Hall around 14, The Reading Room around 21 and everything (96 fragments) around night 32, inside the 25–35 target; rising keeper levels shorten it. No price changes suggested yet.

57 achievements in six sections (`ACHIEVEMENTS` and `SECTIONS` in `src/game/achievements.ts`), shown as bookcases on Title › Grand Catalogue and as "Shelf restored" lines on the end cards. The engine keeps a `RunLog` for each night (`world.runLog`: towers built and sold, fittings, stacks lost and to the chute, absorbs, picks and Doctor's picks, kills by tower kind, Karl's killer, Trebuchet shoves that moved a fruit, Mimic swallows, most fruit slowed at once, best Catalogue chain, pits killed by direct hits, borrowers at the door, the armour, Sisu and mending), reset in `chooseHero` and `resetRunState`. `finishNight` runs once when a night is won or lost: it adds the night to a lifetime `Ledger` and awards anything newly earned (pure `check(ctx)` functions). They're saved under `melongeddon-achievements` (`earned` timestamps plus the ledger), apart from `MetaStats`, and never in dev mode, tests or the simulator (`persistStats`). The first load backfills only what old stats prove: First Night from `wins`, Librarian and Melongeddon Survivor from `hardWins`, the Endless shelves from `endlessBest`. Chaos Librarian (every late slip) can't be earned yet: there are five slips and three can be taken.

## Controls

Mouse or touch to build and select. Keys: `1`–`5` pick a cannon (or choice 1–3 on upgrade cards, an upgrade while the back-room tab is open, 1–4 on the Doctor's picks, and 1–7 for the keeper on Setup), `Q`/`W`/`E`/`R`/`T`/`Y` switch build tabs (R is the keeper's own towers, T the trick shots, Y the heavy cannons), `Enter` presses the main button on Setup, the intro, story cards and end cards, arrows move through the Title menu, `Space` starts the wave or pauses, `P` pause, `S` sell, `O` the Legal Elf's Objection! (during a wave), `B` opens or closes the back-room tab, `C` opens or closes the checkout card (every card, perk, bookmark, keeper rule and slip in the run; it pauses the board), `Esc` close or open the pause menu (Back on Setup and the intro), `+`/`-` speed, `M` sound. Settings (on the Title and in the pause menu) has sound, music, default game speed, reduce motion, and "Show tips again". The Title's How to play covers controls, cannons, keepers, nights and rooms.

The pause menu (`Esc` or the menu button) has Resume, Settings, Restart night and Leave to title. The game remembers your last setup: the Title's Continue starts it again, and the end cards offer Play again, Change setup and Title.

All sound is synthesized in `src/game/audio.ts`; the engine raises cues in `world.sfx` and the UI plays them.

## Status looks

`src/game/drawStatus.ts` draws every status effect, and nothing in it changes a rule. `statusLook(e, world, { small })` is a pure function that picks what one enemy shows in five layers: `body` (one coating, by priority: `ice`, `burn`, `frost`, `poison`, `ink`, `honey`), `particles` (kinds and counts, capped per fruit and halved on a phone), `ground` (`frost`, `ripple` or `dust`), `pips` (shape, colour and count, most important first, four at most) and `motion` (bob, `faceBack`, rock, wobble, shiver, flatten; none animated with `world.reduced`), plus fixed `extras` (stingers, ice cracks in the last `crackAt` seconds, char, burrow, hurt, heal, the General's medal, the "!"). `draw.ts` calls it once per enemy and hands the result to `drawStatusGround`, `applyStatusMotion`, `drawStatusBody`, `drawStatusAbove` and `drawStatusPips`; a painted sprite takes its body look as a tinted copy made once per sprite and look (`tintedSprite`), and a code-drawn stand-in gets an overlay. Every drawing number (sizes, alphas, `maxParticles` 6 and `maxParticlesTotal` 200, `trailLife` 3 s, `maxMarks` 60) is in `STATUS_LOOK`, and `STATUS_COLOR` holds one colour per effect, also used on the enemy card (`effectColor`). Trails and combo marks (scorch, drips, honey prints, frost, a shatter's star, a thermal shock's steam) are drawing state in `world.marks` (`StatusMark`), laid in the enemy step every `trailEvery` and cleared with the wave. Drawing-only enemy fields: `stunBy` (`"bell"` or `"organ"`, set where those stun, so a stun isn't drawn as ice), `charred`, `healT` and `markCd`. `STATUS_LOOK.on = false` draws the old marks instead. Tests: `tests/status-look.test.ts`.

- `src/components/ui.tsx` – shared buttons, the `GameApi` type and labels; `keeperCards.ts` – keeper card data
- `src/lib/saves.ts` – save version and migrations (runs at startup)

Blender bends each painting on a plane pinned at its base and renders the frames the driver lists: for the 30 still tower paintings a 16-frame idle loop (sway and breath) and a 6-frame shot (duck, punch up, settle); for the 7 painted fruit (melon, corn, pumpkin, Karl, pit, gall, borrower) a 12-frame hopping walk (squash on landing, stretch in the air, leaning forward) and a 5-frame flinch; for those fruit a 6-frame pop (squashed flat, then swelling out as it fades; opacity is a frame's optional sixth number, applied by the driver after the render); for the towers a 7-frame build (rising from flat and wide, overshooting, settling). The driver packs them into `public/sprites/anim/<kind>.webp`, `enemy-<look>.webp`, `pop-<look>.webp` and `build-<kind>.webp` and writes `src/game/towerAnims.ts`, `enemyAnims.ts`, `popAnims.ts` and `buildAnims.ts`; a sprite name runs in every group that has it. `draw.ts` plays them: a tower's shot is its cooldown jumping back up, an enemy's flinch its health dropping; each has its own place in its loop; an enemy's walk slows and stops with its status (frozen holds still) and Karl walks slower; status tints are laid over the strip's frame. A killed fruit (gone from `world.enemies` with no health left, not leaked) leaves a ghost where it was last drawn that plays its pop once, under the living fruit, beside the engine's juice burst and stain. A tower first seen after the world's first frame plays its build (`TowerMotion.build`, 0 to 1); one that disappears (sold, or the Anti-Geese Protocol spent) leaves a ghost that plays it backwards, unless more than three go at once (a cleared board). Towers without a build strip (turning cannons, code-drawn ones) get the same rise as a squash and stretch from their base, from `BUILD_ANIM.poses`. Ghosts and the first-frame clock reset when a different world is drawn or its clock goes back (`watchWorld`). The still paintings show while the strips load. Fruit still drawn by code (the rooms' own fruit, the Siege's geese and cats) have no painting to animate yet. Turning cannons recoil in code instead. Needs Python with Pillow and Blender 4+ (found on PATH, as the Microsoft Store's `blender-launcher`, or set `BLENDER` to `blender.exe`).
- `tests/` – engine tests (`node --test`)
- `docs/balance-baseline.md` – simulator report before any rebalancing
- `docs/balance-current.md` – simulator report for the current numbers

## New-player bot

`npm run sim:newplayer` (`scripts/new-player.ts`) plays the game in a real browser as someone who has never seen it, to find where a newcomer gets confused, not to win. It starts its own dev server on a free port and a fresh browser profile (empty storage, developer mode off; your own browser's save is never touched), then: reads the title screen and hovers every button, clicks the locked New night, opens How to play, Settings and the Grand Catalogue, starts the guided first night (trying Back to setup on the poster), follows Mynxi's lessons by reading them (taps the carpet once by mistake, builds beside it by looking at the board's pixels), plays a few more waves, leaves to the title and walks through Setup. It only uses what's on screen (buttons, labels, tooltips, lessons, tips, the log line) and only presses keys the UI has mentioned.

It writes `sim-results/new-player/<time>/report.md` (plus `report.json` and screenshots): friction points worst first (blocker, major, minor, note), each with the screen, what it tried, what it expected and what it saw; words met on screen before anything explained them; and a timeline with each step's words and reading time. Options: `--url http://localhost:5173/` (use a running server), `--headed` (watch it), `--waves 6`, `--viewport 390x844`, `--browser msedge`, `--seed 3`, `--out DIR`. Needs Chrome or Edge installed (it drives them through `playwright-core`, no browser download).

By default it plays as a curious learner (`--style curious`): between instructions it wanders off now and then (`--curiosity 0.4`) to tap its own towers and sometimes sell one, tap the board at random, browse tabs and locked cards, pause, change speed, open the menu and Settings, mash keys, hover the fruit, look round the Back room, try to build what it can't afford, and once in a while hit Skip on a lesson by mistake. Each poke and what came of it is listed in the report; after each one it has to find its own way back to the board. `--style careful` only follows instructions. While other work is changing the code, point it at a fixed build (`npx vite build` then `npx vite preview`, and `--url`) so hot reloads don't pull the page out from under it.

## Tuning

The main knobs are in `BALANCE` in `src/game/rules.ts` (enemy health curve, story-night pace, kill rewards, slow strength, Sir Michael's start, endless health growth), plus `DIFFICULTIES` in the same file. After changing them, run `npm run sim` and compare against `docs/balance-current.md`. `--workers N` splits the runs over N processes (a 5-seed run of everything is 6,400 runs, about an hour on 15 workers); `--set PATH=VALUE` changes an exported rules object for one run without editing it (`--set COMBO.on=false` is the combos-off comparison); `--from a/runs.json,b/runs.json` rebuilds a report from saved runs, a later file's run replacing the same run in an earlier one. A board can ease one difficulty on its own: `Board.trim` (`{ from, count }`: from that wave, groups of 2 or more are cut to that share, through `trimSpawns` in `queueFor`) and `Board.pace` (a speed multiplier in `tune`). The Greenhouse trims Story to 75% from wave 9; the Courtyard walks at 80% on Story and trims Normal to 85% from wave 6.

`docs/balance-current.md` (10 seeds, 12,800 runs) against the review targets: Story is 90% or better on every room (the Stacks 90%, the Siege 93%) and for every keeper (91–97%). Normal is 62–80% by keeper, average 73.5; the Doctor is lowest at 62%, 11.5 points under. The 10-seed run first matched the 5-seed one (the Doctor 58% on Normal and 90% on Story, Quackarot 89% on Story, Asser 83% on Normal), so starting stacks moved: the Doctor 10 → 12 (Normal 62%, Story 91%), Quackarot 11 → 12 (Story 91%, Normal 67%), Asser 25 → 20 (Normal 80%, Story 95%; Hard Lessons now counts 19 missing stacks so it pays out on his last stack). Still weak: Quackarot on the Siege's Story (83%), and the Doctor and Quackarot on the Siege's Normal (38%, 43%). Combos on against off (`--set COMBO.on=false`): nights are within 2 points on Story and Normal, Midnight is 8–11 points easier with combos on above Normal, and the Siege is 7–12 points harder on Melongeddon and Overdue, where its finale's tanks lean on fire patches that a later Freeze hit douses. Vaelithra was the big mover (+26 on Normal) while her slow built frost; it is now its own kind, Drowsy (`DROWSY` in `rules.ts`: half speed, the third hit puts a fruit to sleep, fire wakes it, no frost), tuned back to 93% Story and 66% Normal (4 seeds, `sim-results/drowsy-e`). The Organ's chord, Barbed Spears and Quack-Liber's rocket are a daze now (`Enemy.chill`, no frost); only the Freeze cannon and Cold rind add frost. Melon-only bots still lose Story on the Siege (Box Cats), which mixing towers answers.

**The human bot** (`--strategies human`, `scripts/sim-human.ts`) is a test player that plays like a decent regular player rather than a fixed rotation, for checking a keeper, tower or change the way a person would use it. It keeps one shopping list and saves for the next thing on it (when the floor is thin, fewer cannons than the wave number + 1 up to 8, it buys a plain cannon instead of saving for an extra). It reads this wave and the next through `api.wavePreview` and builds answers first: a Peeler for shells, husks and damp; a `BOX_SEERS` tower before Box Cats (the keeper's own if it has one, else a Still); a cannon that reaches an uncovered paratrooper landing; two cannons on the last stretch for chute fruit; a Mortar for a crowd. It places by the carpet a tower really covers on that tile (`api.previewStats`, so lamps, auras and the Archive's dark count), keeps cannons together, puts a Reading Lamp where it lights three or more unlit cannons and an Ink Well where the most cannons overlap, and adds an Organ late. It buys a back-room fitting when its share of the damage times the fitting's gain beats another cannon for the seeds, and picks the fitting that adds the most. Shelf picks are `smartPick`. Keeper tools follow `KEEPER_PLAN`: the signature at two cannons; Mynxi's Desk by the door; Vael's Flask at six cannons, with Stills in place of Fire; Sir Michael's Roost, Gate and Great pairs (merges from five cannons); the Elf's Stomp and Honey (placed like ink); Ooze's Copycat; the Doctor's Lectern on a useless tile; Quackarot's Quack-Liber in the middle of his cannons, the Post and the Quackmission, and the Anti-Geese Protocol before a boss or a top-threat wave. To stay "decent", it takes one of the three best tiles within 8% of the best (`SKILL`) and looks two waves ahead. Each run reports why it built what it built (`RunResult.tactics`, the report's "human bot's reasons" table); `RunConfig.onPrep` lets tests look at its board before every wave (`tests/human-bot.test.ts`). Against the old bots (`sim-results/human-compare`, 2 seeds, every map, smart picks): human 100 / 96 / 89% on Normal / Melongeddon / Overdue, `mixed` 95 / 82 / 47%, `mixed+mods` 93 / 78 / 45%; it ends with about 54 towers against 34–40. **Scenarios** (`npm run sim:scenario -- FILE.json`, `scripts/sim-scenario.ts`) answer one question by playing the same games two or more ways. A scenario file holds the `question`, `base` flags shared by every variant, and `variants` (name → flags); all are ordinary `npm run sim` flags, so a variant can be a rule change (`--set CANNON.mortarDmg=2.0`), a build plan (`--opener melon,melon,melon,lantern`, which the human bot builds first, in order, each where it belongs, even a kind `--avoid` keeps out after), a tower cap (`--max-towers`), a missing tower (`--avoid`), a keeper choice (`--keeper-at`, `--no-great`, `--armours`, `--perks`) or another bot. The first variant is the baseline, and each other is compared with it game by game: same keeper, difficulty, night, map, seed and armour, so both face the same fruit (`compare` in `scripts/scenario-stats.ts`: the win-rate difference with a 95% range, and when that's too close, the difference in "how far", which counts the share of the night survived on a loss and 1 plus the share of stacks kept on a win). Flags after the file are added to every variant (`--seeds 40`, `--workers 12`). `focus` names a tower to report how often it was built and its damage share. The report (`sim-results/scenario-<name>/report.md`) starts with a plain answer, then each variant's numbers and a win rate per keeper, map and difficulty when the scenario covers several; each variant's full sim report sits in its own folder beside it. Examples in `scripts/scenarios/`: `lamp-three-melons` (a lamp beside three melon cannons on the Stacks, Hard and Overdue), `mortar-damage` (the Mortar at ×2.4 against ×2.0), `michael-roost-timing` (the Roost at five cannons or ten). Tests: `tests/scenario.test.ts`.

**The abuse bot** (`--strategies abuse`, `ABUSE` in `scripts/sim-human.ts`) is the human bot with one plan: find the strongest thing and spam it. It keeps the human bot's answers (shells, Box Cats, drops, chutes), lamps and keeper towers, drops its Ink Wells and late Organ, and merges every Great pair it can as Sir Michael. Its candidates are the five shared shooters that look best on paper (damage per second × reach per seed) plus two at random; it spams the kind that did the most damage per seed in the waves just played (each wave scored on its own, the latest counting most), trying the next candidate every third build through wave 7. Every fitting goes to that kind and every shelf pick that reaches it (its own upgrade first). On a thin floor it buys the best-measured kind it can afford rather than saving for its pick. `--abuse KIND` pins the kind from the start. `RunResult.abused` and the report's "What the abuse bot spammed" table say what it settled on. Left to itself it settles on the Brass Telescope nearly every night: the Telescope really does the most landed damage per seed (it aims for Karl, armoured fruit and the toughest), but a floor of Telescopes leaks swarms and loses, so "most damage per seed" is not "most powerful". **The spam screen** (`npm run sim:abuse`, `scripts/sim-abuse.ts`) asks the question by results instead: a scenario with one variant per shared shooting tower (`SPAM_KINDS`: the abuse bot pinned to it), the abuse bot's own pick, and the human bot as the baseline, over the same games (default: every keeper, the Stacks, Annex and Sorting, Normal and Hard, 2 seeds; `--base "..."` and `--kinds a,b` narrow it). Its report ranks them, and a spam marked **better** than the human bot is a candidate exploit. First screen (on dev 7108101, 96 games a variant, `sim-results/abuse-screen`): the human bot 83%; **spamming the Pipe Organ 95%** (+11 ± 7 points, the only spam better than the human bot: about 15 Organs a night doing 74% of the damage; Hard 67% → 90%, the Doctor 58% → 100%, Quackarot and Ooze 75% → 100%); then the Ballista 64%, Rolling Globe 61%, Freeze 59%, Melon 58%, down to the Still 13% and the Bookworm 6%; the abuse bot's own pick (the Telescope 70 times in 96) 54%. **The pair screen** (`npm run sim:abuse -- --pairs`) does the same for combos: `--abuse a,b` pins the abuse bot to two kinds, its cannons split evenly (it builds whichever it has fewer of) and every fitting and shelf pick aimed at both; the screen plays every pair of `PAIR_KINDS` (the best single spams plus the status-combo pieces: Organ, Ballista, Melon, Globe, Orrery, Quill, Freeze, Fire, Mortar, Fly Hive; `--kinds` to change) beside each kind alone and the human bot (default: every keeper, the three maps, Hard and Overdue, 1 seed, `sim-results/pair-screen`), and ends its report with a "Combos" table: each pair against the better of its two halves over the same games, **real combo** when the pair wins clearly more. Tests: `tests/abuse.test.ts`.

Targets used for the current numbers: a cautious player (2 towers per wave) wins ~90% on Story, ~60–70% on Stacks, ~35–45% on Melongeddon; a player who builds whenever they can wins ~90% on Stacks and ~50% on Melongeddon.
