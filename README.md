# Melongeddon

A single-player tower defense: defend the Midnight Library from melons, corn, and pumpkins.

Standalone Vite + React + Tailwind project, extracted from the original Grok app-builder export.

**New here? Read the [Setup and Player Guide](docs/GUIDE.md)**: how to install and run it, publish your own copy, and how to play (controls, keepers, towers, upgrades, enemies, nights and tips).

Play online (once GitHub Pages is on): https://jorthalion.github.io/melongeddon_v1/

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build into dist/
npm test         # engine tests
npm run sim      # balance simulator -> sim-results/report.md (add -- --seeds 10 for more runs)
```

## Publishing

The build uses relative paths, so `dist/` runs from any folder or domain.

- **Windows installer:** `npm run installer` writes `release/installer/Melongeddon-Setup-<version>.exe` (Electron; code in `electron/`, settings under `"build"` in `package.json`). Pushing a tag like `v0.2.0` runs `.github/workflows/release.yml`, which builds, smoke-tests (`MELONGEDDON_SMOKE=1`) and publishes it as a GitHub Release. See the guide for the long-path workaround.
- **Installable web app:** the hosted build is a PWA (`public/manifest.webmanifest`, `public/sw.js`). The build writes `dist/precache.json` (every file) so the service worker can cache the whole game for offline play; the Title shows **Install app** when the browser offers it. Fonts are bundled (`@fontsource-variable`), so offline copies look the same.

- **itch.io:** `npm run package` writes `release/melongeddon-web.zip`. Full step-by-step page setup, description, tags, cover and screenshots: [docs/itch/ITCH.md](docs/itch/ITCH.md).
- **Netlify:** connect the repo (settings come from `netlify.toml`), or drag the `dist/` folder onto app.netlify.com/drop.
- **GitHub Pages:** push to GitHub, then in the repo's Settings → Pages set Source to "GitHub Actions". `.github/workflows/pages.yml` tests, builds and deploys on every push to `main`/`master`.

Optional: once you know the final URL, make `og:image` in `index.html` an absolute URL so link previews show the poster.

## Nights

Midnight is 21 waves (`MIDNIGHT_WAVES`; `nightLength(night)` gives each night's length). Act one is waves 1–6; act two is the next nine and ends on Unchaperoned; act three is six more waves, climbing slowly from wave-15 health. A shelf opens after wave 15. Act three brings three new fruit, all flags on existing kinds (`pit`, `gall`, `borrower` on `SpawnSpec`), each with its own sprite (`public/sprites/enemy-pit.webp`, `enemy-gall.webp`, `enemy-borrower.webp`; a ring or dot stands in while they load). Galls draw last, so a rider is never hidden under the pumpkin behind its host. A **pit** is a stone melon: splash, fire and puddles do only `BALANCE.pitResist` (12%) of their damage to it, so a direct shot does the work; it is not a guard, so the Peeler can't strip it. A **gall** is a small corn rider that sits a step behind a pumpkin and heals it `BALANCE.gallHeal` (6%) of its health a second while both live; pop the rider and the pumpkin is only a pumpkin. A **borrower** is a fast, frail corn that costs no stack at the door but takes `BALANCE.borrowTake` (12) seeds. The finale, "The stacks, again", is Karl with borrowers ahead of him. The Overflow is still 15 waves (`WAVE_COUNT`) and doesn't use act three's fruit. Nobody comes to the door: the knight's visit, its alliance and its betrayal were removed. The Overflow ends with "The meter spends" and "Up the chute", when absurdity drops rinds down the chute. Enemy health climbs the full curve through wave 6, then `BALANCE.storyHpPace` (0.375) of a step per wave up to wave 15, so wave 15 is as tough as the old 10-wave finale. From wave 15, Midnight's act three keeps climbing at `BALANCE.actThreeHpPace` (0.3) of a step a wave (`storyHpStep`), and each of its waves puts a mix behind its one new fruit, so waves 16–20 climb into Karl instead of resting before him. The Overflow multiplies enemy health by `BALANCE.overflowHp` (1.4): at 1.0 the simulator won 96% of Overflow nights on Normal against 69% for Midnight; at 1.4 it is 72% on Normal and 35% on Melongeddon (Midnight: 38%).

**The Overflow's chute.** From wave 6, some fruit come up the returns chute: they appear past the far end of the carpet and walk it backwards, and one that reaches the entrance costs a stack. Waves 6–9, 11, 13 and 14 send shelled melons up it; waves 14 and 15 also drop a shelled melon per 25 absurdity, and wave 15 sends Karl. A **CHUTE** plate and arrows mark that end of the carpet: they glow blue and move while the current or next wave uses the chute (`hud.chuteWave`), and sit dim otherwise. The first chute wave also shows a one-time tip (`melongeddon:chute-tip`; Settings › Show tips again brings it back).

**The Siege (night three).** `NightId` `"siege"`, 15 waves (`SIEGE_WAVES` in `rules.ts`, through `waveAt`) on its own map, `BOARDS.courtyard` (22 × 14, a 46-tile `carpet: "path"` with two 45° stretches, hedges, six `statues` and a 2 × 2 `fountain` as shelf cells, and two `drops`). It opens after the Overflow: the Catalogue ledger counts story wins by night (`Ledger.winsByNight`, filled by `addNight`; `parseSave` backfills an Overflow win from an old `winsByMap.overflow` or the Overflow achievements), `hud.siegeOpen` reads it (developer mode opens it; `WorldOptions.siegeOpen` forces it for the simulator and previews, `WorldOptions.ledger` seeds it for tests), and `chooseNight("siege")` refuses with "Win the Overflow first." until then. The Overflow's victory card offers **Continue to the Siege** (`api.continueSiege`; `victoryAction` in `keys.ts` names the button and Enter does the same); the Siege's offers **Set up Endless**. It starts with the keeper's usual seeds plus `BALANCE.siegeSeeds` (60, shown on the checkout card's "Tonight" group with the Overflow's crates), climbs the story health curve with no multiplier of its own, and pays fragments like the Overflow (`FRAGMENTS.siegeBonus`). Its intro is its own poster ("Night three", "The Siege", `SIEGE_JOKE`). There is no fruit in it: two new kinds, **`goose`** and **`cat`** (`STATS`), and six flags on them (`SpawnSpec` `gosling`, `matriarch`, `boxed`, `para`, `tank`, `general`; `QueueItem.siege`). Every number is in `SIEGE` in `rules.ts`. A plain goose is a **Honker**: its first hit sets `Tower.honked` on every tower within `honkReach` (1.5 tiles), which skips its next shot. **Goslings** come in lines of `goslingLine` (5; `QueueItem.line`, the first is the `leader`); a dead leader halts its line `goslingStun` (2 s, `Enemy.halt`). **The Matriarch** (boss) sets `rallied` on every goose every `rallyEvery` (6 s) for `rallyTime` (3 s) at ×`rallySpeed` (1.5). A plain cat is **Private Whiskers** (`lives9`): the first lethal hit leaves it at `nineLives` (30%) unless it was one hit from full health worth `oneLife` (130%) of it. A **Box Cat** is skipped by every tower's aim except the area towers in `BOX_SEERS` (the Cauldron and the Quack-Liber count: they lob a puddle or a burst); splash, burn, pulp or a Reading Lamp's reach knocks the box off (`unbox`). A **Paratrooper** never walks in: its queue item becomes a pending landing (`world.landings`) that lands on `BOARDS.courtyard.drops[drop]` after `dropGlow` (3 s), under a parachute for `dropFall` (`descend`), and `hud.dropWave` lights the targets before the wave. A **Cardboard Tank** takes ×`tankArmour` (0.5) from a shot or splash whose source (the tower, or where a splash landed) is ahead of it along the carpet, and costs 2 stacks at the door (`leakOf`). **General Mittens** (boss) gives every cat ×`generalBonus` (1.25) health while she lives (`mittened`), and on her death every cat loses it and walks back `scatter` (2 s, through `driven`). Both bosses cost 3 stacks and pay +2 stacks like Karl. **The feud** (`tickFeud`): a non-boss goose and cat within `feudReach` (half a tile) both `halt` for `feudTime` (2 s) and lose `feudHit` (10%) of their max health (`hurt` via `"feud"`, which skips every modifier), once per pair, drawn as a dust cloud (`world.brawls`). The **Anti-Geese Protocol** throws geese ×`protocolThrow` (2) as far and sets `panic` (`protocolPanic`, 2 tiles), walked back in the Driver's branch. One-time tips (`SiegeTip`, keys `melongeddon:siege-tip:feud` and `:drop`) show the first fight (`hud.feuds`) and the first drop (`hud.dropSeen`). The geese, cats, hedges, statues, fountain and flagstones are drawn by code in `src/game/drawSiege.ts` until their sprites (`enemy-honker`, `-gosling`, `-matriarch`, `-whiskers`, `-boxcat`, `-para`, `-tank`, `-general`, `tile-floor-courtyard`, `prop-hedge`, `prop-statue`, `prop-fountain`, registered in `draw.ts`) exist; prompts are in `docs/art/ENEMY_PROMPTS.md` and `docs/art/PROMPTS.md`. Achievements: a "Courtyard" set on the Atlas Room shelf (`Achievement.set`), counted in `RunLog.feuds`, `protocolGeese`, `boxesOff` and `oneLife`. Tests: `tests/siege.test.ts`. Tuning (simulator, `--seeds 2`, Story / Normal / Melongeddon / Overdue): the Siege wins 73 / 47 / 16 / 6% against the Overflow's 88 / 53 / 23 / 13% (4 seeds: 76 / 50 / 17 / 7%), with geese at 36 health, cats 45, tanks 140, the Matriarch 340, the General 380 and 60 extra seeds; fewer Box Cats and paratroopers than first written, and one fight at a time per animal (otherwise a stopped cat fought every goose that walked up and whole waves jammed at the entrance). Nearly all of the Story gap is the melon-only bot (31%), which has no answer to a Box Cat; the other bot strategies win 87% on Story, as on the Overflow.

**Simulated balance** (bots, 1 seed per setup, so ±7 points of noise): every keeper lands in the same range as the original three. The bots pick upgrades at random and rarely use the back room, so they undersell the Doctor's fourth choice and the Elf's discount.

## Difficulty

Four levels on the setup screen. They scale enemy health and speed (`DIFFICULTIES` in `src/game/rules.ts`):

| Level | Health | Speed | Simulated bot win rate |
|---|---|---|---|
| Story | 0.75× | 0.9× | ~97% |
| Normal | 1× | 1× | ~77% |
| Melongeddon | 1.2× | 1.12× | ~41–49% |
| Overdue | 1.45× | 1.15× | ~25% |

Bots are not smart players, so read these as relative. Wins on Melongeddon and Overdue are counted in the saved stats (`hardWins`); the first one unlocks the Reading Room.

## Endless mode

Pick **Endless** as the night on the setup screen (New night). You play act one's six waves, then generated waves that cycle four themes (corn swarms, shelled melons, pumpkins, a mix), grow every other wave, and add armoured variants from wave 13. Karl comes every fifth wave. You get an upgrade pick after waves 1, 2 and 6, then every fifth wave. Enemy health follows the story curve to wave 10, then grows `BALANCE.endlessGrowth` (15%) per wave. In simulation, Normal runs end around waves 17–19 and Easy around 25. Best endless score is saved separately.

## Cannons

23 cannons in five build tabs (`Q`/`W`/`E`/`T`/`Y`, then `1`–`5`; `R` is the keeper's own):

- **Damage:** Melon, Mortar, Seed Spitter (rapid, pings off shells), Shelf Ballista (its spear goes through the first `CANNON.ballistaPierce` (4) fruit on its line, nearest first; the `pierce` fitting, Through and through, adds `ballistaPierceMore` (3); `ballistaPierce(mods)` in `rules.ts`, shown as `pierce` in its stats), Long Reader (whole-board sniper, hits the toughest)
- **Control:** Still, Fire, Freeze, Shush Bell (area stun; husks are deaf), Fly Hive (homing, whole board; each fly does 60% of a melon shot). Shots live as long as their trip needs (`shotLife` in the engine: the distance at `SHOT_SPEED`, plus a second), so the hive and the Reader land anywhere on the biggest maps.
- **Support:** Reading Lamp (boosts neighbours), Ink Well (+25% damage taken), Peeler (strips shells/husks/damp), Bookworm (damage over time on pumpkins and Karl), Compost Heap (seeds every wave)
- **Trick:** Boomerang Bookend (elliptical loop out and back, pierces, one hit each way), Orrery (three planets orbit the tower and hit what they sweep, 0.5 s per planet per fruit), Paper Plane (a glider that steers toward the nearest fruit at a limited turn rate, so it swoops in arcs; 0.45 s between hits on the same fruit), Serpent Quill (a quill that flies out in a sine wave to 1.6× its range, hitting each fruit it crosses once), Rolling Globe (lobs a globe onto the carpet just ahead of the lead fruit; the landing thuds everything within 34 px, then it rolls back along the carpet toward the entrance, hitting each fruit in its way once)
- **Heavy** (`Y`, every keeper; locked until wave 6 or 200 seeds in hand that night, `HEAVY_WAVE` / `HEAVY_SEEDS`): Printing Press (200: every 2.9 s a sheet lands on the lead fruit and slides back up the carpet 220 px, hitting each fruit once for 70 and inking it: +25% damage taken for 4 s), Pipe Organ (220: every 2.5 s a chord hits every fruit within 1.25× reach for 59 and slows it 1.2 s; every third chord also stops it 1 s, 0.35 s on Karl; husks take the damage but ignore the slow and the stop), Brass Telescope (250: 3.2× reach, instant shots of 168 every 0.77 s that ignore shells, husks and damp; aims for Karl, then armoured fruit, then the toughest). Each has its own fittings: Broadsheet and Wet ink for the Press, Bigger pipes and Crescendo stop for the Organ, Longer barrel and Quick wick for the Telescope. Tuned in the simulator (melons plus one kind, all keepers, 3 maps) to about the Ballista's level, before counting the ink, slows and armour piercing the bots don't use: Press 67% Normal / 33% Hard, Organ 65% / 28%, Telescope 67% / 22% (melons alone 59% / 24%, melons + Ballista 76% / 33%). Knobs: `PROFILE.press/organ/scope` and `CANNON.press*` / `CANNON.organ*` in `rules.ts`.

**Trick shots.** Boomerangs, planes, quills and globes are `Flyer`s (`world.flyers`), moved by `moveFlyer` in the engine; the Orrery's planets are computed per tower in `spinOrrery`. Numbers are the `boomerang*`, `orrery*`, `plane*`, `quill*` and `globe*` keys in `CANNON` plus their `PROFILE` rows. In simulation (Midnight, the Stacks, bot builds melons plus one other kind), win rates are: melons only 58%, + Ballista 61%, + Paper Plane 69–70%, + Serpent Quill 72%, + Orrery 74%, + Boomerang 75–80%, + Rolling Globe 76%.

**Trick cannons open with keeper levels** (`TRICK_LEVEL` in `src/game/rules.ts`): Boomerang Bookend at level 2, Orrery 3, Paper Plane 5, Serpent Quill 7, Rolling Globe 9. It's the playing keeper's level when the night starts (`hud.runLevel`), so each keeper opens them separately, and a level reached mid-night counts from the next night (the level-up message names the cannon). Locked cards show a lock and "Level N" in the build bar. Developer mode has every keeper at level 10. The simulator and most tests pass `allTricks: true` to `createWorld` so bots can build any of them. The trick cannons, the boomerang, plane and quill in flight, and the three orrery planets are painted sprites (`public/sprites/trick-*.webp`, `fly-*.webp`); the globe in flight is still drawn in code. Image prompts are in [docs/art/TRICK_PROMPTS.md](docs/art/TRICK_PROMPTS.md).

**Cannon upgrades.** Five of the new cannons have an upgrade in the between-wave picks: Barbed Spears (Ballista: spear slows), Footnotes (Reader: hits ink the target), Stinging Flies (Hive: each fly hits a second fruit), Ink Blot (Ink Well: popped marked fruit splash ink, marks sting harder) and Interest (Compost: +20 per heap plus 10% of unspent seeds, up to 20). Each also makes its own cannon fire faster. One is offered only once you've built that cannon, never at the first pick, and it takes the middle slot so the keeper's own pick stays. It doesn't change which picks come next. Knobs are in `CANNON` (`upgradePace`, `readerUpgradePace`, `inkUpgradePace`, `blotInkBonus`, `blotRadius`, `interestBase`, `interestRate`, `interestCap`).

In simulation (bot always takes the cannon upgrade vs never), Barbed Spears, Footnotes and Stinging Flies are about level with the general pick they replace. Ink Blot and Interest still trail by roughly 20 points: both boost other cannons or reward saving seeds, which the bot doesn't plan for. The simulator accepts a `pickUpgrade` chooser in `RunConfig` for this kind of test.

The ten newer cannons are drawn in code (`src/game/drawCannons.ts`) until there is painted art. Their stats are in `PROFILE` and `CANNON` in `src/game/rules.ts`. Upgrade on-hit effects (Juicy, Splatter, Electric) only fire from the original four shooting cannons, so rapid-fire cannons don't multiply them.

## Maps

Night one (and Endless) can be played on any unlocked map. Night two is always the Overflow, and night three, the Siege, is always the Courtyard.
 Boards are defined in `BOARDS` in `src/game/rules.ts` as a list of carpet corners, plus one tile kept open as floor on every board (`michaelCannon`, once Sir Michael's free cannon; now just a buildable tile) and the bookshelf cells (`shelves`, default `DEFAULT_SHELVES`). **Bookshelves block building:** `shelfCells(map, path)` gives the blocked cells (never on the carpet or on that kept-open tile), the world keeps them as `world.shelfCells`, the build marker and `pointer` refuse them ("That's a bookshelf"), the bots skip them, and the board draws its shelves from the same set. With shelves blocking, melon-only bots on the Stacks win 54% (58% before) and melon + Boomerang 76% (80%), within the simulator's noise.

| Map | What's different | Unlocked by |
|---|---|---|
| The Stacks | the original carpet | always open |
| The Annex | the carpet folds back on itself | always open |
| The Mezzanine | balcony across the top, floor across the bottom, open middle | restoring The Mezzanine |
| Rare Books | spiral to a door in the middle; fruit have 25% more health (`hp` on the board) | restoring Rare Books |
| The Archive | dark: cannons have 20% less range unless a Reading Lamp reaches them (`BALANCE.archiveDark`) | restoring The Archive |

| The Reading Room | big (22 × 14): three long lanes, cannons between lanes cover two; fruit have 40% more health | restoring The Reading Room |
| The Sorting Room | big (22 × 14), 42-tile carpet; three 6-tile belt columns (`floors`) carry fruit ×`FLOOR.belt` (1.6) the carpet's way, ×1/1.6 against it; `hp` 0.8; its fruit: Express Corn and the Parcel | restoring The Sorting Room |
| The Greenhouse | big (22 × 14), 48-tile carpet with one 45° stretch; 9 growth-bed tiles heal `FLOOR.bedHeal` (5%) of max health a second unless the fruit burns; `damp`: burning ×0.55; `hp` 0.85; its fruit: the Sprout and the Creeping Squash | restoring The Greenhouse |

**Floors.** A board may list `floors`: straight runs of carpet tiles (`from`/`to`, in the carpet's direction) that are a `belt`, `up` or `down` stairs, or a growth `bed`. `floorTiles(map)` expands them to `world.floors` ("c,r" to kind and direction); the movement step multiplies by `floorPace(kind, back)` (walking toward the entrance, a chute walker or a driven fruit, takes the inverse). Beds heal in the enemy loop unless the fruit burns. A board with a `bell` gets `world.bell` (`next`, `quiet`), counted down by `tickBell` during waves and reset at each wave start; while `quiet` is above 0 the tower loop skips every tower. The marks are drawn by `drawFloors` and `drawBell` in `draw.ts`; painted art is listed in `docs/art/MAP_PROMPTS.md`, and the design notes are in `docs/new-maps-design.md`.

**Targeting.** Each aiming tower has a `Tower.target` (`TargetMode`: first, last, strong, weak, close, armour, boss, fresh) chosen in the inspector or with `A` (`api.cycleTarget`); its kind's recommended mode and the modes it offers are in `DEFAULT_TARGET` (`rules.ts`), `fresh` ("first, not affected") uses `FRESH_TEST` in `engine.ts`, and a new tower starts on the mode last set on its kind that night.

**Screen layout.** `layoutFor` (`src/lib/layout.ts`) works out the board's drawn width in the normal layout (board over the build bar) and the wide one (build column left, back room right) and picks wide only if its board is at least as big, within `WIDE_SLACK_PX`; both lose `BAR_REM` to the Coming up bar. Tips (`TipCard`, `Tips` in `TutorialHint.tsx`) never sit on the board: MelonGame's tip dock puts them in a line under the Coming up bar (a `more` toggle; `TipFit`), in full in the wide layout's right column, and above the build bar under `NARROW_PX` (640). Under `NARROW_PX` the Back room is a button beside Start wave (`BackRoomTab compact`, passed to `BuildFooter` as `backRoom`); its panel still opens as a sheet over the board. Tests: `tests/layout.test.ts`, `tests/tips-layout.test.ts`.

**Coming up bar.** `api.wavePreview(index)` returns a wave as it will walk in: `queueFor(index)` builds the queue for both the preview and `startWave` (late-slip extras, room fruit via `assignNatives`), and `spawnNumbers` gives each enemy's real health and speed (Siege sizes, mini-bosses, borrowers). Groups of identical enemies, notes for mid-wave extras, a threat (health × speed, bosses ×3, tanks ×2) ranked 1–5 against the night, a trend and up to three flags. `api.comingUp()` is the next wave between waves and what's still queued (plus landings) during one. `counters.ts` holds one table of what beats what, read by `ComingUpBar`'s "Your towers don't answer…" line and the enemy card's "Beaten by". Settings switch: `melongeddon-wavebar`. `tests/wave-preview.test.ts` plays every wave of every story night (and 30 Endless waves) and checks the preview against what spawned.

**Status combos.** Part one's numbers are in `COMBO`, part two's in `AFFLICT` (`rules.ts`; `COMBO.on` switches both off for the simulator). Frost (`Enemy.frost`, 0–3, beside the old `freeze`/`chill` timers; `iced` = held by a Freeze hit; bosses cap at 2; damp drains slower), shatter in `hurt()` on the first splash at 2+ frost (bonus, splash shards that can't shatter, afflictions spent), thermal shock (`thaw`, via `"shock"`, so raw pumpkins don't bake) and `douse` (a doused fruit is still steaming: no fire, but no bed or vine healing either), wildfire (`tickAfflictions`, rate halved when damp), `explode()` for puddles and fire patches. Afflictions: `sting`, `poison` (the Cauldron's puddle now stacks it, a third of the puddle a stack), a fruit's own `burnT`/`burnDps`, ticked through `hurt` (`"sting"`, `"poison"`) under `AFFLICT.cap`; `contagion()` at death; `flamed` spends poison when the fire goes out. Fittings `deepfreeze`, `blackice`, `shrapnel`, `wildfire`, `barbs`, `virulent`, `grit`. Run log `shatters`, `thermals`, `wildfires`, `contagion`, `maxStung`, `maxAfflictions` feed six Workshop achievements; `hud.comboTips` drives `ComboTip`.

**Rounded carpets and diagonals.** A board may set `carpet: "path"` (the Sorting Room, the Greenhouse and the Bell Tower do): `drawBand` draws the carpet as one band along `world.points` with each turn rounded (centre radius half a tile) and a gold rule on both edges, and fruit within reach of a turn are drawn on the curve (`roundedSpot`); their rules position stays on the corner. A stretch between corners runs straight or at exactly 45° (`buildBoard` throws otherwise; floors must be straight). A diagonal's carpet is its diagonal tiles; the two half-covered tiles beside each step are `world.vergeCells`: nothing can be built there (`VERGE_NOTE`), they count as beside the carpet for the Pamphlet, the Reserve Desk and the Gourd Gate (`besideCarpet`, `legsTouching`), and nothing else treats them as carpet.

**Room fruit.** A board may set `natives: { common, elite }` (a `NativeId`; only the Sorting Room, the Greenhouse and the Bell Tower do). `buildQueue` expands the shared wave with `waveQueue` and `assignNatives` swaps fruit in place: from wave `NATIVES.commonFrom` (4) every `commonEvery` (4)th plain fruit of the common's base kind, and from `eliteFrom` (10) the first plain fruit of the elite's base kind (two from `actThreeFrom`, 16; none on Story). A plain fruit has no guard or flag and isn't Karl or a chute fruit. Each is a flag on the enemy (`native`): Express Corn ignores slows, stops, honey and the Driver on a belt and rides it at `expressBelt` (2); a Parcel is `wrapped` (direct hits ×`parcelWrapped`, any splash, burn or pulp unwraps it) and drops `parcelContents` (3) corn that pay nothing; a Sprout grows into a melon after `sproutGrow` (2) s on beds or vines unless burning; a Creeping Squash lays `world.vines` every `vineEvery` (1.5) s that heal like a bed for `vineLife` (6) s, burn away under fire and wither `vineWither` (1) s after it dies; each Chimer runs the clock `chimerRush` (25%) faster, up to `chimerMax` (2×); a Gargoyle Gourd moves ×`gargoyleAwake` (3) while the bell's `quiet` is on and takes ×`gargoyleSkin` (0.75) otherwise. The first of each per night sets the log line in `NATIVE_INFO` and `hud.nativesSeen`, which shows the room's one-time `NativesTip`. Sprites `enemy-express`, `-parcel`, `-sprout`, `-squash`, `-chimer`, `-gargoyle` and `tile-vine` are registered in `draw.ts` with drawn stand-ins until the art lands (prompts in `docs/art/ENEMY_PROMPTS.md`).

**Board size.** A board may set `cols`/`rows` (default 16 × 10); `boardSize(map)` gives cells and world pixels, and the world carries them as `world.cols/rows/w/h`. Drawing, input (`fitBoard`), previews and the simulator all read the world's size, so a bigger board simply draws at a smaller scale. `GLOBAL_RANGE` (1400 px) is larger than the biggest board's diagonal. Without their health bonus the long carpets made the big maps much easier (Midnight on Normal: Great Hall 89%, Reading Room 97%, Stacks 71%). With `hp` 1.2 and 1.4 they simulate at 69% / 46% (Great Hall) and 82% / 32% (Reading Room) on Normal / Melongeddon, against 71% / 42% for the Stacks.

Maps open with Grand Catalogue rooms (`ROOMS` in `src/game/catalogue.ts`; `MAP_GOALS` in `meta.ts` only holds the "Restore …" text). Map cards and the intro screen draw the real board (`src/components/MapPreview.tsx`). In simulation the five classic maps play within a few points of the Stacks. Rare Books is the easiest without its health bonus; the Archive is the hardest for the bot, which doesn't plan lamp placement.

## Late slips

The Overflow's setup screen offers up to three optional **late slips** (`src/game/slips.ts`): Heavy Returns (chute opens on wave 3), Damp Powder (−20% damage), No Refunds (selling pays 0), Short Shelf (−4 stacks) and Karl Is Early (extra Karl on wave 8). Each adds keeper XP (+10% to +25%, bonuses add). Picks save with the setup record; the simulator takes them through `slips` in `RunConfig`.

## Mynxi's tutorial (guided first night)

A new player's first **Start** plays Mynxi's tutorial: Midnight on the Stacks as Mynxi, on Normal, made very easy. Fruit have 30% of their health and 80% of their speed, and the night starts with +80 seeds and +8 stacks (`tutorialHp`, `tutorialSpeed`, `tutorialSeeds`, `tutorialStacks` in `BALANCE`; applied through `tune()` and `tutorialStart()` while `hud.tutorial` is on, restarts included). In simulation, a player who builds only the two cannons the lessons ask for holds with no leaks to wave 8; one who adds a cannon every third or fourth wave wins; one who adds a cannon a wave wins without a leak. She talks the player through 13 lessons in a speech box (`src/components/MynxiTutor.tsx`):

1. **Talk** (Next): welcome, the carpet and stacks, seeds.
2. **Build** a Damage cannon, then the range ring (talk).
3. **Build** a Control or Support tower, then the five tabs, the keeper tower and trick cannons (talk).
4. **Start** the wave, then speed and pause (Next, or change the speed), and holding the carpet.
5. **Pick** an upgrade card after wave 1.
6. **Open** the back-room tab before wave 2 and buy an upgrade (that one is free).
7. A last word on selling (talk).

Talk steps have a Next button; the others wait for the player, and building early skips the lessons it covers. The wave won't start while a step before it is open (`GUIDE_HOLDS`); pressing Start wave says why. Leaving the back room saves `melongeddon-guide` = `done` and opens **New night**. For the rest of that night (`hud.tutorial`) she chips in once each for a leak, Karl, affording her Card Catalogue, and the win or loss. **Skip** (on the box, or **Skip the guide** on the Title) ends it, and **Tutorial** on the Title replays it (`api.startTutorial()`). The steps are `GuideStep` / `GUIDE_STEPS` / `GUIDE_TALK` in the engine; her lines are `LESSON` and `TIPS` in the component. Her four expressions (`FACE`) all use the portrait until the art in [docs/art/MYNXI_PROMPTS.md](docs/art/MYNXI_PROMPTS.md) arrives. Tests and the simulator never see the tutorial unless they pass `guide: true` to `createWorld`.

## Saves

Saves are separate `localStorage` keys; `melongeddon-save-version` says which layout they are in (`SAVE_VERSION` in `src/lib/saves.ts`, now 1). `migrateSaves()` runs before anything reads them: saves with no version (v0.5.0 and earlier) count as version 0 and are migrated (players with progress skip the guided night); an unreadable version clears progress but keeps preferences; a newer version is left alone; a save that isn't valid JSON is dropped. To change a save layout, bump `SAVE_VERSION` and add a step to `MIGRATIONS`.

## Developer mode

Settings › **Developer mode** (`melongeddon-dev` in localStorage) reloads the game with `ALL_UNLOCKED` stats and `maxedProgress(0)` keepers, a DEV badge, and `api.devSeeds()` (+`DEV_SEEDS`, 500) in the pause menu. While it is on, lifetime stats, best waves and keeper XP are not written (`persistStats`, `persistKeepers`), so switching it off restores the real progress. Tests can pass `dev: true` to `createWorld`.

## Keeper levels

Each keeper levels from 1 to 10 by clearing waves as that keeper (10 XP a wave, +50 for a win, scaled by difficulty: Story ×0.5 up to Overdue ×2). Levels 2, 4, 6, 8 and 10 each open a choice of two perks, picked on the setup screen and swappable before any night. Level 10 offers a second copy of the keeper's signature tower or a keeper-specific capstone. Data, XP curve and storage live in `src/game/levels.ts`; the engine applies the merged effects (`perkFx`) when a run starts. The full perk list is in [docs/GUIDE.md](docs/GUIDE.md#keeper-levels-and-perks).

Simulated win rates (all strategies, maps and doors, one seed): level 1 is 69% on Normal and 38% on Melongeddon; a level 10 keeper is about 80% and 50%. Ooze gets slightly bigger perks and Sir Michael smaller ones. Dr. Samodovol's perks bend the Doctor's pick and the Lectern (Footnote, Annotated, Cited Edition, Midpoint, Carried Note, Second Opinion, Lecture Notes, Close Reading, and Second Lectern alone at level 10). Quackarot's perks bend his turret: its reach and speed-up (Wide Wake, Steady Hands), its burst (Heavy Payload), a speed-up after its kills (Quiet Confidence), a slowing patch every fourth rocket (Lane Lockdown), sticky targets (Covering Fire), and at level 10 a second turret with a slowing line between the two (Defensive Perimeter). The simulator takes keeper levels through `keepers` in `RunConfig`.

## The Grand Catalogue (fragments, rooms, achievements)

**Rooms and fragments** (`src/game/catalogue.ts`). Fragments come from finished nights (`FRAGMENTS`, `nightFragments`: a story win pays 1/2/3/4 by difficulty, +1 for the Overflow, +1 for popping Karl, 1 for a story loss after wave 10, 1 per 10 Endless waves) and from achievements (their `tier`, paid once, via `settle` in `achievements.ts`). They're spent on `ROOMS` (`restoreRoom` on the Title or Setup); each room's `rewards` open maps, keepers, bookmarks, keeper towers and cosmetics at once. `unlockedMaps`, `unlockedIds` and `lockedTowers` in `meta.ts` now take the restored rooms; `hud.lockedKeepers` gates `pickKeeper`/`chooseHero`, and `validateSetup` falls back to Mynxi with a note. A new player has only The Stacks (Mynxi, Vaelithra, Sir Michael, the Stacks and the Annex). Tests, the simulator and dev mode see every room (`options.rooms` picks some for tests). Cosmetics (`Cosmetics`: carpet dye, keeper-card frame, gilded title) are code-drawn, chosen in Settings › Appearance, and never touch play. **Migration:** on the first load after the change, `migrate()` restores for free every room with a reward the player already had under the old goals (kept as `LEGACY` in `catalogue.ts`: maps, bookmarks, keeper towers) or a keeper with XP, pays for achievements already earned, and leaves a one-time note on the Title. The save is the achievements key, `melongeddon-achievements`, now also holding `fragments`, `fragmentsEarned`, `rooms`, `migrated` and `cosmetics`.

**Balance (estimate).** Simulated Normal nights on the Stacks at level 1 (mixed strategies) pay about 2.0 (Vaelithra, 67% wins) to 2.8 (Mynxi, 92%) fragments a night before achievements; early achievements add roughly 3 on the first night and about 20 over thirty. Buying rooms cheapest first, the first room comes after night 1, The Archive around night 5, The Great Hall around 14, The Reading Room around 21 and everything (96 fragments) around night 32, inside the 25–35 target; rising keeper levels shorten it. No price changes suggested yet.

57 achievements in six sections (`ACHIEVEMENTS` and `SECTIONS` in `src/game/achievements.ts`), shown as bookcases on Title › Grand Catalogue and as "Shelf restored" lines on the end cards. The engine keeps a `RunLog` for each night (`world.runLog`: towers built and sold, fittings, stacks lost and to the chute, absorbs, picks and Doctor's picks, kills by tower kind, Karl's killer, Trebuchet shoves that moved a fruit, Mimic swallows, most fruit slowed at once, best Catalogue chain, pits killed by direct hits, borrowers at the door, the oath, Sisu and mending), reset in `chooseHero` and `resetRunState`. `finishNight` runs once when a night is won or lost: it adds the night to a lifetime `Ledger` and awards anything newly earned (pure `check(ctx)` functions). They're saved under `melongeddon-achievements` (`earned` timestamps plus the ledger), apart from `MetaStats`, and never in dev mode, tests or the simulator (`persistStats`). The first load backfills only what old stats prove: First Night from `wins`, Librarian and Melongeddon Survivor from `hardWins`, the Endless shelves from `endlessBest`. Chaos Librarian (every late slip) can't be earned yet: there are five slips and three can be taken.

## Controls

Mouse or touch to build and select. Keys: `1`–`5` pick a cannon (or choice 1–3 on upgrade cards, an upgrade while the back-room tab is open, 1–4 on the Doctor's picks, and 1–7 for the keeper on Setup), `Q`/`W`/`E`/`R`/`T`/`Y` switch build tabs (R is the keeper's own towers, T the trick shots, Y the heavy cannons), `Enter` presses the main button on Setup, the intro, story cards and end cards, arrows move through the Title menu, `Space` starts the wave or pauses, `P` pause, `S` sell, `B` opens or closes the back-room tab, `C` opens or closes the checkout card (every card, perk, bookmark, keeper rule and slip in the run; it pauses the board), `Esc` close or open the pause menu (Back on Setup and the intro), `+`/`-` speed, `M` sound. ## Status looks

`src/game/drawStatus.ts` draws every status effect, and nothing in it changes a rule. `statusLook(e, world, { small })` is a pure function that picks what one enemy shows in five layers: `body` (one coating, by priority: `ice`, `burn`, `frost`, `poison`, `ink`, `honey`), `particles` (kinds and counts, capped per fruit and halved on a phone), `ground` (`frost`, `ripple` or `dust`), `pips` (shape, colour and count, most important first, four at most) and `motion` (bob, `faceBack`, rock, wobble, shiver, flatten; none animated with `world.reduced`), plus fixed `extras` (stingers, ice cracks in the last `crackAt` seconds, char, burrow, hurt, heal, the General's medal, the "!"). `draw.ts` calls it once per enemy and hands the result to `drawStatusGround`, `applyStatusMotion`, `drawStatusBody`, `drawStatusAbove` and `drawStatusPips`; a painted sprite takes its body look as a tinted copy made once per sprite and look (`tintedSprite`), and a code-drawn stand-in gets an overlay. Every drawing number (sizes, alphas, `maxParticles` 6 and `maxParticlesTotal` 200, `trailLife` 3 s, `maxMarks` 60) is in `STATUS_LOOK`, and `STATUS_COLOR` holds one colour per effect, also used on the enemy card (`effectColor`). Trails and combo marks (scorch, drips, honey prints, frost, a shatter's star, a thermal shock's steam) are drawing state in `world.marks` (`StatusMark`), laid in the enemy step every `trailEvery` and cleared with the wave. Drawing-only enemy fields: `stunBy` (`"bell"` or `"organ"`, set where those stun, so a stun isn't drawn as ice), `charred`, `healT` and `markCd`. `STATUS_LOOK.on = false` draws the old marks instead. Tests: `tests/status-look.test.ts`.

## Tuning

The main knobs are in `BALANCE` in `src/game/rules.ts` (enemy health curve, story-night pace, kill rewards, pulp puddle rate, slow strength, Sir Michael's start, endless health growth), plus `DIFFICULTIES` in the same file. After changing them, run `npm run sim` and compare against `docs/balance-current.md`. `--workers N` splits the runs over N processes (a 5-seed run of everything is 6,400 runs, about an hour on 15 workers); `--set PATH=VALUE` changes an exported rules object for one run without editing it (`--set COMBO.on=false` is the combos-off comparison); `--from a/runs.json,b/runs.json` rebuilds a report from saved runs, a later file's run replacing the same run in an earlier one. A board can ease one difficulty on its own: `Board.trim` (`{ from, count }`: from that wave, groups of 2 or more are cut to that share, through `trimSpawns` in `queueFor`) and `Board.pace` (a speed multiplier in `tune`). The Greenhouse trims Story to 75% from wave 9; the Courtyard walks at 80% on Story and trims Normal to 85% from wave 6.
